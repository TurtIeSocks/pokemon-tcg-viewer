# Site i18n (UI chrome) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the site UI chrome (nav, buttons, headings, empty states, form labels, toasts) into all 12 catalog languages via Paraglide, on a `uiLanguage` axis independent of the existing card-content language.

**Architecture:** Paraglide (inlang) compiles `messages/{locale}.json` → typesafe `m.*()`. Locale = `profile.uiLanguage` (source of truth) carried by a `ui-lang` cookie. SSR resolves per-request via Paraglide's server middleware (`AsyncLocalStorage`); client re-localizes in place when `profile.uiLanguage` changes. No URL locale segment; home/series/set drop from prerender to full SSR so first paint is locale-correct.

**Tech Stack:** TanStack Start (Router + Nitro SSR), React 19, Zustand, `@inlang/paraglide-js`, native `Intl.*`, Bun test.

## Global Constraints

- **Package manager: bun** (`bun.lock`). Never npm/yarn/pnpm. After dep changes run `bun install` and commit `bun.lock`.
- **12 locales, in this order:** `en, fr, de, es, it, pt, ja, ko, zh-tw, zh-cn, th, id`. `baseLocale = en`.
- **Cookie name: `ui-lang`.** Card cookie `ptcg-lang` is a SEPARATE axis — never conflate.
- **No em-dashes in any user-facing copy, including translations.** Periods/commas only.
- **Optional persisted fields are `null`, never `undefined`.**
- **Do NOT touch `src/store/userland/money.ts`** — money stays deterministic (out of scope).
- **Manual `useMemo`/`useCallback` are intentional** (React Compiler on) — don't strip them.
- **Tests must not hit the network** — pre-seed `useCorpusRuntime.setState({ index: buildIndex([...]) })` in any test rendering a card grid.
- **Bun test:** use `spyOn`, never `mock.module` (it poisons later test files).
- **Lint in worktree:** `bunx biome check --config-path=. <files>` (plain `bun run lint` fails on nested biome.json).
- **`src/paraglide/` is generated + gitignored** (like `routeTree.gen.ts`); a `postinstall` compile regenerates it.

/** Cookie carrying the chosen SITE-UI language for SSR first-paint (separate from ptcg-lang, which is card content). */
export const UI_LANG_COOKIE = "ui-lang";

/**
 * Persist the site-UI language to its cookie (client-only; no-op on the server).
 * Read server-side by Paraglide's cookie strategy so a cold SSR load renders chrome
 * in the right locale before the client store hydrates.
 */
export function writeUiLangCookie(lang: string | null | undefined): void {
	if (typeof document === "undefined") return;
	if (lang && isSupportedLanguage(lang)) {
		// biome-ignore lint/suspicious/noDocumentCookie: necessary
		document.cookie = `${UI_LANG_COOKIE}=${lang}; path=/; max-age=${LANG_COOKIE_MAX_AGE}; SameSite=Lax`;
	}
}
```

	async fetch(request: Request, opts?: unknown) {
		return paraglideMiddleware(request, async ({ request: localizedRequest }) => {
			const res = await handler(localizedRequest, opts as never);
			const contentType = res.headers.get("content-type") ?? "";

import type { ReactNode } from "react";
import { setLocale } from "../paraglide/runtime";
import type { SupportedLanguage } from "./languages";
import { updateProfile } from "../store/userland/userland-store";
import { useUserland } from "../store/userland/userland-store";
import { bcp47 } from "./bcp47";

/**
 * Switch the site-UI language. Persists to profile (which mirrors the ui-lang
 * cookie), then updates Paraglide's active locale WITHOUT a full reload
 * (reload: false) — <LocaleBoundary> re-renders the tree on the profile change.
 */
export async function setUiLanguage(lang: SupportedLanguage): Promise<void> {
	await updateProfile({ uiLanguage: lang });
	setLocale(lang, { reload: false });
	if (typeof document !== "undefined") {
		document.documentElement.lang = bcp47(lang);
	}
}

/**
 * Re-renders its subtree whenever profile.uiLanguage changes so every m.*()
 * call re-evaluates in the new locale. Subscribing to the store field is enough;
 * no separate version counter is needed.
 */
export function LocaleBoundary({ children }: { children: ReactNode }): ReactNode {
	// Subscribe so a uiLanguage change re-renders this subtree.
	useUserland((s) => s.profile?.uiLanguage);
	return children;
}
```

Guard `main()` behind `if (import.meta.main)` so importing the module for tests doesn't run it. `mergeTranslations(existing, fresh, force)`:
```typescript
export function mergeTranslations(
	existing: Record<string, string>,
	fresh: Record<string, string>,
	force: boolean,
): Record<string, string> {
	if (force) return { ...existing, ...fresh };
	const out = { ...existing };
	for (const [k, v] of Object.entries(fresh)) {
		if (!(k in out)) out[k] = v;
	}
	return out;
}
```
