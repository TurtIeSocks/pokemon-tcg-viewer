# Phase 0.1a — Stack Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the per-copy record into a **Stack** (N identical cards via a `quantity` field), add `source`/`storageLocation` provenance, and migrate the snapshot schema v1→v2 — without breaking existing data or tests.

**Architecture:** Rename `CollectionItem`→`Stack` (and `Copy*`→`Stack*`) as a mechanical first pass that keeps the suite green, then layer new behavior with TDD: `quantity` (default 1) + per-unit price math in counts, two nullable provenance fields, a runtime normalize-on-read migration, a v1→v2 backup upgrade, a `splitStack` action, and form/UI wiring. All optional fields stay `null`, never `undefined`.

**Tech Stack:** TypeScript, Zustand (`userland-store`), IndexedDB via the repo port (`repo.ts`/`idb-repo.ts`), TanStack Form, Bun test runner (`bun test`), happy-dom + Testing Library.

```ts
const SUPPORTED = new Set([1, 2]);

export function isValidSnapshot(v: unknown): v is { schemaVersion: number; collection: unknown[]; binders: unknown[] } {
  if (!isRecord(v)) return false;
  if (typeof v.schemaVersion !== "number" || !SUPPORTED.has(v.schemaVersion)) return false;
  if (!Array.isArray(v.collection) || !Array.isArray(v.binders)) return false;
  const itemsOk = v.collection.every((i) => isRecord(i) && typeof i.id === "string" && typeof i.cardId === "string");
  const bindersOk = v.binders.every((b) => isRecord(b) && typeof b.id === "string" && typeof b.name === "string");
  return itemsOk && bindersOk;
}

/** Upgrade any supported snapshot to the current v2 shape. */
function upgrade(snap: { schemaVersion: number; collection: Record<string, unknown>[]; binders: unknown[] }): UserDataSnapshot {
  const collection = snap.collection.map((c) => ({
    ...c,
    quantity: typeof c.quantity === "number" && c.quantity >= 1 ? c.quantity : 1,
    source: (c.source as string | null) ?? null,
    storageLocation: (c.storageLocation as string | null) ?? null,
  })) as unknown as UserDataSnapshot["collection"];
  return { schemaVersion: 2, exportedAt: Number(snap.exportedAt) || 0, collection, binders: snap.binders as UserDataSnapshot["binders"] };
}

export function parseSnapshot(json: string): UserDataSnapshot {
  let data: unknown;
  try { data = JSON.parse(json); } catch { throw new Error("That file isn't valid JSON."); }
  if (!isValidSnapshot(data)) throw new Error("Unrecognized or unsupported backup format.");
  return upgrade(data as Parameters<typeof upgrade>[0]);
}
```

```ts
export async function splitStack(id: string, count: number): Promise<string> {
  const src = useUserland.getState().items[id];
  if (!src) throw new Error("Stack not found");
  if (!Number.isInteger(count) || count < 1 || count >= src.quantity) {
    throw new Error("Split count must be between 1 and quantity - 1");
  }
  const { id: _id, createdAt: _c, isPrimary: _p, ...fields } = src;
  const peeled = await activeRepos().collection.add({ ...fields, quantity: count });
  await updateStack(id, { quantity: src.quantity - count });
  useUserland.setState((s) => ({ items: { ...s.items, [peeled.id]: peeled } }));
  return peeled.id;
}
```
