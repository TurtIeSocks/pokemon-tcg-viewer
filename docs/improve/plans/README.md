## Findings considered and rejected

- **loaderDeps "missing params" on `$card.tsx` / `$set/index.tsx`** (subagent CORRECTNESS-04/05): false positive — TanStack Router keys route matches on path params and always re-runs loaders when they change; `loaderDeps` receives only `{ search }` by API design. No bug.
- **History-state `cardTab` runtime validation / card-slug regex** (TANSTACK-01/02): no reachable impact path — unknown slugs resolve to `undefined` → handled `notFound`; TS-level enum + error boundary cover the rest.
- **`head()` optional-chaining inconsistency** (TANSTACK-03): loader throws `notFound()` first; defensive chaining is fine as-is.
- **Imperative `navigate()` for search-param updates** (TANSTACK-06): idiomatic; no action.
- **Dirty-set read-modify-write in cache-repo** (RACE-03): mitigated by conditional `clearDirty` (only snapshotted-AND-pushed ids are cleared); worst case is one debounce-cycle latency. Not worth code.
- **srcSet string rebuilds in holo-card** (PERF-3/9): string concat is negligible; React Compiler memoizes the render. Not worth code.
- **Fuzzy-search O(n) per keystroke** (PERF-6/7): already behind `useDeferredValue` + a query cache + length-pruned edit distance; no measurement showing jank. Re-open only with a profile in hand.
- **`getBoundingClientRect` per pointermove in use-holo-effect** (PERF-8): holo vars affect paint/composite, not layout, so the read doesn't force reflow; spring already rAF-driven; single hovered element only. Not worth code.
- **Port HoloCard image FSM into the SSR island fallback** (DEBT-03): fallback is documented-intentional ("crawlable, no hydration risk"); full FSM port is high-risk for a rare 404 flash. The shared-src part is covered by plan 003.
- **Replace owned-missing-grid tiles with full HoloCard** (DEBT-04): grid is deliberately lightweight/non-virtualized for binder-sized lists; foil FX per mini-tile would cost more than the duplication. Shared-src covered by plan 003.
- **Move server types to src/lib re-exports** (DEBT-05): `import type` from server modules is erased at compile time; no runtime coupling exists. Churn without payoff.
- **Split `src/components/ui/sidebar.tsx` (729 lines)**: vendored shadcn primitive; splitting diverges from upstream and complicates regeneration.
- **`syncDetail`-style guard in `enableOffline`**: user-initiated action; no race against user intent.
- **loadCorpus fetch dedupe**: verified correct (per-region in-flight promise map) — recorded here so nobody re-audits it.
