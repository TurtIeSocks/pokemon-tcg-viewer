# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

**In short:** be respectful, welcoming, and constructive. Assume good faith.
Harassment, discrimination, personal attacks, and other unwelcoming behavior are
not tolerated — in issues, pull requests, commits, or any other project space.

## Reporting

Report unacceptable behavior to the repository maintainer (open a confidential
issue, or contact the repo owner directly). Reports are handled discreetly.

Maintainers may remove, edit, or reject comments, commits, code, and
contributions that violate this Code of Conduct, and may temporarily or
permanently ban any contributor for behavior they deem inappropriate.
